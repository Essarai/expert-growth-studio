# 达人获客助手

面向达人的短视频获客与运营助手交互原型，当前以婚姻家事律师账号展示业务流程。

## 运行与检查

```sh
npm ci
npm test
npm start
```

本地访问 http://localhost:4173/ 。静态页面位于 dist，无需后端。

## 页面

今日运营、账号策略、内容工作室（包含发布管理）、客户中心（咨询接待、评论洞察、客户跟进）、效果分析、达人档案。

今日运营聚合需人工处理的事项，按客户和内容去重；等待客户回应不重复催办。评论触达经确认后进入接待，并关联客户档案。

所有账号、对话、数据与动作均为本地示例，不连接真实平台、AI 或发送消息。部分研究编辑保存在浏览器 localStorage，其他状态刷新后重置。请勿输入真实客户资料。

## 视觉规范

字号固定为 14 / 18 / 24。基础样式位于 dist/ui-system.css，客户中心布局位于 dist/customer-center.css，最终公共组件规范位于 dist/components.css。按钮分主操作、普通操作、轻操作；页面标签栏使用下划线，筛选使用浅色选中态。

## 发布

GitHub Actions 验证交互后将 dist 发布到 GitHub Pages。
